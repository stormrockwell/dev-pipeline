# Potential v2

Ideas kept out of v1 on purpose. Each entry says what it is, why it waits, and what would bring it back.

## Open Code Review managed mode

**What it is.** OCR runs the whole standards review itself instead of handing it to Claude Code. That adds what delegation mode skips: file bundling, a toolset tuned on production review traces, comment positioning and reflection, and benchmarked precision at about a ninth of the tokens of a general agent. It also brings OCR's GitHub Action, which posts inline PR comments with a sticky summary.

**Why it waits.** Managed mode and the Action need their own model endpoint and API key, and v1 runs every model call through Claude Code on the team's plans.

**What would bring it back.**
- Phase 0 shows delegation adds little, while standards review takes a real share of plan usage or misses findings humans catch.
- OCR gains a way to run its engine through Claude Code or a subscription.
- The team decides an API budget for review is worth it.

**How to adopt it.** Run managed mode as a third arm of the Phase 0 standards comparison, behind the same adapter, and switch only if it wins on precision and plan usage without losing recall on planted issues.
