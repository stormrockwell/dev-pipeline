# Spike 0.5: claude plugin eval harness

| Case | Passed? | Notes |
| --- | --- | --- |
| sqli | yes (1.00) | Regex `sql.?injection\|prepare` matched findings.md, Skill fired once. |
| missing-nonce-cap | yes (1.00) | Lookahead regex required both `nonce` and `capabilit\|current_user_can`, Skill fired once. |
| unescaped-output | yes (1.00) | Regex `xss\|cross.?site\|unescaped\|esc_html\|esc_attr\|escap` matched, Skill fired once. |
| clean-control | yes (1.00) | `not_contains` on `\[(CRITICAL\|HIGH)\]` passed, and a second grader required `No findings` or a MEDIUM/LOW line so a missing file cannot pass. |

Each case ran once on sonnet (n=1, so skill-trigger reliability and false-positive rate are unmeasured). Cost was about $0.07 and 20 s per run, $0.28 and 75 s for the suite.

Findings:

- Graders are deterministic, so `regex` over `{ source: file, path: findings.md }` grades produced files, while `tool_used` grades the Skill call, with `llm` graders optional and `--judge-model` defaulting to haiku. There are no custom-code graders, regex is JavaScript only (no inline `(?i)`, use `flags: i`), and `not_contains` on a missing file passes vacuously, so pair it with a positive grader.
- Regexes are keyword matches, so they cannot confirm a finding cites the right line or that the severity is correct, and loose patterns such as `prepare` or `escap` can pass on an unrelated mention.
- `--scaffold` is required for `context.scaffold_script`, and the script runs in the empty workspace with a minimal env (no `EVAL_*`, temp `HOME`), so `git config user.*` must be set inside it.
- `--trust-plugin` is required when stdin is not a TTY, otherwise the run is refused with exit 1.
- No sandbox, grader or scaffold errors occurred. Bash under `--allow-tools "Bash(git *)"` ran sandboxed without issue, and `Skill` is listed in `allowed_tools` in each prompt.md.
- The skill-fired grader is excluded from the score under the default `with-without` ablation, but `--ablation none` scores it, as it did here.

Command (run from `spikes/0.5-evals/`):

```
claude plugin eval . --trust-plugin --scaffold --runs 1 --ablation none --model sonnet --no-publish --allow-tools Write Edit "Bash(git *)"
```

Verdict: `claude plugin eval` is enough for a planted-defect regression suite (git fixtures, regex and tool graders, CI exit codes), but not for judging finding precision or severity, which needs `llm` graders or a separate scorer.
