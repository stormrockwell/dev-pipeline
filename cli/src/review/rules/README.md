# Vendored review rules

These rule docs come from Open Code Review by Alibaba, at tag v1.13.3 (commit dd925205e108304bd4dd6cc0f8e8b7cf8dee77ea), from `internal/config/rules/rule_docs/`. They are used unchanged under the Apache License 2.0, a copy of which is in `LICENSE` beside them.

`pipeline review files` serves them when the `ocr` CLI is not installed, so the standards reviewer keeps working with the same rules OCR's delegation mode resolves. The path map in `../rules.ts` follows OCR's `system_rules.json` for the files these docs cover.

Source: https://github.com/alibaba/open-code-review
